Домашнее задание

Создать динамическое меню, которое выгружается из базы данных через
вызов процедуры.

+ В базе данных должна быть представлена таблица со следующими колонками:
  1. Id
  2. Название (name)
  3. Действие (action)
  4. Отмечаемый (checkable) 

+ Добавление пунктов меню осущестляется через процедуру

+ Получение содержимого всей таблицы - также через процедуру

+ Название - это тот текст, который должен быть виден пользователю после запуска
приложения

+ Действие - имя метода, который должен выполняться при активации пункта меню
(Методы заранее прописаны: открыть, сохранить, закрыть).

+ Отмечаемый - будет ли этот пункт меню Checked или нет.
