Создать кеширующий midleware в ASP.NET Core MVC приложении.

При первом запросе к ресурсу необходимо выполнить next для доступа к контроллеру.
После получения ответа его необходимо сохранить в кеширующем сервисе (внедрить сервис как singleton) для повторного использования.
При повторном запросе ответ нужно возвращать из кеша.

Привести пример применения middleware для вычисления чисел Фибоначчи

Должен быть контроллер Fibonacci с методом Index, который принимает параметр - число, для которого
необходимо вычислить значение числа Фибоначчи.
пример: http://localhost/Fibonacci/Index/5

Где 5 - это число, для которого вычисляется числол Фибоначчи
