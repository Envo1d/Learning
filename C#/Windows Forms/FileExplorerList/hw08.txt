Создайте приложение на базе TreeView для просмотра
каталогов файлов с вложенными каталогами (аналог проводника).

После запуска приложения отображаются диски, который можно получить через класс DriverInfo
(см. https://docs.microsoft.com/en-us/dotnet/api/system.io.driveinfo.getdrives?view=net-5.0)

Содержимое директорий не загружать до тех,пор пока не будет раскрыт узел (нажатие на +)
Для этого использовать событе BeforeExpand.

Файлы и катологи должны отображаться с разными иконками.

Раскрытый каталог должен отображаться с иконкой раскрытого каталога.
Закрытый католог - с иконкой закрытого католога.

Предусмотреть обработку исключений в случае, если доступ к катологу требует прав администратора.

Дополнительные задания:

1. Добавить контекстное меню для удаления и переименования файла/католога
2. Удалить выбранный файл или католог при нажатии на кнопку Delete на клавиатуре
3. Открыть файл при двойном клике левой кнопкой мыши или нажатии Enter на клавиатуре
4. Переименование файла или католога при нажатии клавиши F12
