# C# Keyword Highlighter

**Topics:** Windows Forms, desktop events and application state.

**Difficulty:** Intermediate.

**Target:** .NET Framework 4.7.2 Windows Forms.

## Exercise and Implementation

Open C# files in a RichTextBox, highlight recognized keywords, and accept files through drag and drop.

## Requirements and Material Status

Includes keyWords.xml, loaded by LoadKeys from the working directory. This exercise demonstrates keyword-based highlighting rather than a complete C# parser.

Open the original `.sln` in this directory with Visual Studio on Windows and build tools for the declared target framework. Keep the project structure and supporting files together. Runtime image/XML paths are relative to the working directory unless the code specifies otherwise. Any database or external file requirements must be prepared separately.

## Archive Notes

Imported from `WindowsForms8` inside the supplied `WinForms.7z` archive. The original solution, project, C# source, designer files, form resources, properties, configuration, supplied user settings, and included data/assets were copied without changes and checked using file hashes. Generated `bin`/`obj` directories, restored `packages`, and Visual Studio's `.vs` data are excluded. Assignment-only documents retain their original text format and encoding.

The source was inspected for classification. The project was not built or run, and behavior and correctness were not exhaustively verified.
