# Fruit and Vegetable Database Viewer

**Topics:** Windows Forms, database access, SQL, and desktop events.

**Difficulty:** Advanced learning exercise.

**Target:** .NET Framework 4.7.2 Windows Forms.

## Exercise and Implementation

Select an ADO.NET provider, obtain configured connection settings, query fruit and vegetable records, and display colors, counts, calorie statistics, and filtered results.

## Requirements and Material Status

Includes DB.sql, App.config, and Task.txt. Uses DbProviderFactories and provider-neutral connection/adapter classes, but changing providers still requires suitable installed providers, connection settings, and a compatible schema and SQL dialect. Provider switching was not verified.

Open the original `.sln` in this directory with Visual Studio on Windows and build tools for the declared target framework. Keep the project structure and supporting files together. Runtime image/XML paths are relative to the working directory unless the code specifies otherwise. Any database or external file requirements must be prepared separately.
